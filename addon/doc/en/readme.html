Discord Message Hotkeys

Read recent messages in the Discord desktop client without moving your focus or your caret. You can be typing in the compose box, press a hotkey to hear an earlier message, and carry on typing where you left off.

The add-on loads automatically when you are in the Discord desktop application. It does not affect Discord in a web browser.

Reading recent messages

Alt plus a number reads one of the last ten messages in the channel or direct message you currently have open:

  • Alt+1 reads the newest message.
  • Alt+2 reads the message before that, and so on.
  • Alt+9 reads the ninth newest message.
  • Alt+0 reads the tenth newest message.

Your focus and caret do not move, so these keys are safe to press while composing a message.

Discord only keeps the messages near your current scroll position available to a screen reader, so fewer than ten may be readable. When that happens the add-on tells you how many are loaded rather than reporting an error. If you are not in a channel or direct message at all, it says so quickly instead of searching.

Replying to a message you have just heard

Press the same reading hotkey twice quickly to reply to the message it read. Alt+1 Alt+1 replies to the newest message, Alt+3 Alt+3 replies to the third newest, and so on. The two presses must be within about half a second of each other, which is the same timing NVDA uses for its own double-press commands.

The add-on selects the message, asks Discord to reply to it, and then says "Replying to" followed by the author's name. Your typing cursor is left in the compose box with the reply attached, so you can type your answer and press Enter as usual.

Like Alt+D below, and unlike a single press, this deliberately moves your focus, because a reply has to be attached to a message Discord considers selected. If anything goes wrong the add-on tells you instead of leaving you typing into nothing: it says the message could not be selected, that Discord's reply command could not be found, or that no reply opened.

Jumping to your first unread message

Alt+D moves focus to the first unread message, which is the message just after Discord's "New messages" marker. NVDA reads the message you land on, and Discord's own Up and Down arrows then walk through the rest.

Unlike the reading hotkeys, this one deliberately moves your focus, because being taken to the message is the point of the command.

If there is no unread marker in the channel, the add-on tells you there are no new messages. If the marker is scrolled far out of view it may not be findable, and the add-on says that too.

Reviewing a message

When focus is on a message in the message list, for example after moving there with the arrow keys or Alt+D, or the browse mode cursor is on one in the new client, Alt+V opens that message in a read-only window. The author is a heading, followed by the full date, what it replies to, the text in its own paragraphs, and lists of links, attachments and reactions. Read it with the arrow keys, Ctrl+Left and Ctrl+Right for words, or Home and End, and press Escape to close it.

Jumping to the server and channel lists

Ctrl+Shift+S moves focus to the server you are in, in the server list. On the Friends page or in a direct message it lands on the first item, Direct Messages.

Ctrl+Shift+C moves focus to the channel you are in, in the channel list. Outside a server it goes to the direct messages list instead: to the conversation you have open, or to the first direct message when you are on the Friends page.

Ctrl+Shift+Z moves focus to the message box in the channel or direct message you have open. In a channel where you can't send, NVDA reads Discord's "You do not have permission" notice from the box. On the Friends page it moves focus to the first friend in the list instead.

Ctrl+Shift+A moves focus to the first person in the Active Now panel on the Friends page. Discord hides that panel when the window is narrow.

Ctrl+Shift+X moves focus to the user status and settings area at the bottom left: voice details and Disconnect while you are in a call, then your profile, Mute, Deafen and settings.

The current server and channel are taken from the Discord window title. If the add-on can't match them, for example because the channel is scrolled out of the list, it goes to the first item instead.

Browse mode in the new Discord client

Discord's new client (the Rust "Phoenix" app) is not a web page, so NVDA on its own offers no browse mode there: no reading with the arrow keys, no quick navigation, no Elements List. The add-on provides one. It works like browse mode on a web page:

  • Up and Down arrows move line by line. Each message is one line, "author, text, time" (a long message continues on the lines after it), followed by anything you can act on in it: links, reactions, attachments, and for a reply, one "Jump To Reply" line saying who and what it replies to. Each server, channel, direct message, friend and member is one line too: on the Friends page, "name, user name, status, activity", then its Message and More options buttons.
  • A message that starts a new group of messages is a heading, so H and Shift+H jump from author to author, as in the old client.
  • Quick navigation keys work: H for headings, K for links, B for buttons, F for form fields, E for edit fields, L for lists, I for list items (in the message list, one message at a time), S for separators (the date and "New messages" dividers), and D for landmarks. The landmarks are the sections Discord's F6 moves between: the top bar (Back, Forward, Inbox), the server list, the channel or direct message list, your user area, the channel header, the page itself (the conversation, Friends, Quests, Shop and so on), and the member list or profile panel when it is open. NVDA's Article command also moves message by message; it has no key by default, so assign one under Preferences, Input Gestures, Browse mode if you want it.
  • NVDA+F7 lists links, headings, buttons, form fields and landmarks. NVDA+Ctrl+F finds text.
  • Discord's hover tooltips, such as the ones on the buttons beside the message box, are read as the button's description when you move to it with B or Tab, rather than as separate lines.
  • Enter or Space activates what you are on: opens a direct message or link, presses a button, opens a server or tab.
  • NVDA+Space switches between browse mode and focus mode, as usual. Moving to the message box switches to focus mode by itself so you can type, and Escape returns to browse mode.
  • NVDA+F5 refreshes the document straight away.

The document follows Discord as it changes. While you are in browse mode it is brought up to date every few seconds, and when you return to it from focus mode, without moving you: if new messages arrive while you are reading, you stay on the message you were on.

Alt+V in browse mode opens the message you are on, wherever the browse mode cursor is, without first moving focus to it.

The Electron client already has NVDA's own browse mode, so nothing changes there. To turn this off for the new client, open the NVDA menu, choose Preferences, then Settings, select the Discord Message Hotkeys category and clear Use browse mode in the new Discord client.

Reading new messages automatically

Alt+Shift+N cycles automatic reading of incoming messages in the channel you have open, through three modes:

  • Off — no automatic reading. This is the default.
  • Polite — a new message waits until NVDA has finished whatever it is currently saying.
  • Interrupt — a new message is spoken straight away, cutting off current speech.

Switching this on does not read the messages already on screen. Only messages that arrive afterwards are announced. The same is true when you change channel: the existing conversation is never dumped at you.

Automatic reading only happens while Discord is the focused application, and only for the channel you have open. The mode is remembered when NVDA restarts.

You can also set the starting mode without using the hotkey. Open the NVDA menu, choose Preferences, then Settings, and select the Discord Message Hotkeys category. The setting there and the Alt+Shift+N hotkey control the same option, so they always agree.

Changing the key assignments

All of these commands can be reassigned. In the NVDA menu choose Preferences, then Input Gestures, and look under the Discord Message Hotkeys category.

Reporting a problem

NVDA+Ctrl+Shift+F10 saves a description of Discord's current accessibility structure to a file named discord_nvda_dump.txt in your Downloads folder, and tells you when it has finished. Attaching that file to a bug report makes a problem far easier to diagnose, because it shows exactly how Discord was presenting the message list at the time.

This command is intentionally awkward to press, because the file it writes contains message text. If you use it often, you can give it an easier key under Preferences, then Input Gestures.

Please be aware that this dump contains the text of messages that were on screen when you pressed the key. Read through it, or remove anything private, before sharing it publicly.
